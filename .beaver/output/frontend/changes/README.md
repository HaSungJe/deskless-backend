# 프론트 수정 요청

백엔드가 공개 API(주소 · 요청 · 응답 · 실패 · 동기/큐)나 사용자에게 보이는 동작을 바꾸면, 같은 커밋에 이 폴더에 문서 한 건이 생긴다. 위에서부터 차례로 반영하고, 어디까지 반영했는지는 프론트 저장소에 적어 둔다. 화면 배치 · 디자인은 오지 않는다(화면은 프론트가 정한다) — 기능과 동작만 온다.
