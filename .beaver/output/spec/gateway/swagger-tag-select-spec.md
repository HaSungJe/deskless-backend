## 1. Swagger 도메인 선택 — `GET /swagger`

**동작 흐름**

1. Swagger 화면을 열면 Authorize 버튼과 같은 줄 왼쪽에 도메인 선택 상자가 나온다. 목록은 "전체" 다음에 화면에 보이는 도메인 순서 그대로다.
2. 처음에는 "전체"가 골라져 있어 모든 도메인이 보인다.
3. 도메인을 고르면 이름이 정확히 같은 도메인 묶음만 보인다 — "업체"를 골라도 "업체 둘러보기" · "업체 예약"은 숨는다.
4. "전체"를 다시 고르면 모두 보인다. Swagger 기본 글자 필터 칸은 어느 때도 나오지 않는다.

**입력**

| 필드 | 필수 | 설명 |
|---|---|---|
| 도메인 선택 | | "전체" 또는 Swagger 태그 하나 |

**결과**

| 상황 | 응답 | 테스트 |
|---|---|---|
| 화면을 처음 연다 | 선택 상자 "전체", 도메인 11개 모두 보임 | — (게이트웨이 화면 설정 — spec 없음, build 가 빌드 결과로 브라우저 확인) |
| "회원"을 고른다 | 회원 묶음만 보임 | — (위와 같음) |
| "업체"를 고른다 | 업체 묶음만 — 업체 둘러보기 · 업체 예약은 숨음 | — (위와 같음) |
| "전체"로 돌아간다 | 모두 보임, 글자 필터 칸 없음 | — (위와 같음) |

## 결정한 것

- [x] **선택 상자만, 글자 검색 칸은 두지 않는다.** 사용자 결정 2026-11-18.
- [x] **이름이 정확히 같은 도메인만 보인다.** Swagger UI 기본 필터는 부분 일치라(`node_modules/swagger-ui-dist/swagger-ui-bundle.js` 의 `opsFilter` — `tag.indexOf(phrase)`) "업체"를 고르면 "업체 둘러보기" · "업체 예약"도 남는다. 태그 이름에 겹침이 있어(`@ApiTags` — `apps/gateway/src/api/v1/**/controllers/*.ts`) 정확히 같음으로 바꾼다.
- [x] **Swagger UI 플러그인으로 넣는다(화면 DOM 을 바깥에서 고치지 않는다).** `@nestjs/swagger` 12 는 `swaggerOptions` 안의 함수를 글자로 바꿔 페이지 초기화 스크립트에 넣는다(`node_modules/@nestjs/swagger/dist/swagger-ui/helpers.js` `buildJSInitOptions`). 그래서 플러그인 함수는 바깥 변수 · import 를 쓰지 않는다. 플러그인 목록을 주면 기본 목록(`DownloadUrl`)이 통째로 바뀌므로(`constants.js` 초기화 템플릿) 기본 플러그인도 다시 넣는다.
- [x] **선택은 화면을 새로 열면 "전체"로 돌아간다.** 기억하지 않는다(요청 범위 밖).
