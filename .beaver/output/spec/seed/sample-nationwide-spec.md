# 전국 테스트 업체

## 한눈에

- **무엇을** 테스트 데이터(`SEED_SAMPLE_DATA=1`)에 전국 17개 시 · 도의 업체 61곳을 더한다(서울 10곳은 그대로 — 모두 71곳). 지역 특징대로 편의시설(온천 지역은 온천, 휴양지는 반려동물 · 주차 · 식사)과 주변 관광지를 적은 소개, 객실(휴양지는 2룸 + PC 포함)을 넣고 업체마다 사진을 그린다.
- **왜** 다음 작업 ③ AI 대화형 검색이 "주변 온천 + 반려동물", "휴양지 3곳 추천", "제주 여행지 두 곳 사이 · PC · 방 2개 이상" 같은 대화로 업체를 찾는데, 지금 테스트 업체는 서울 10곳뿐이라 시험할 수 없다.
- **범위 밖** AI 검색 자체(③), 운영 DB 에 넣는 실제 업체, 문의 · 예약 같은 다른 샘플 데이터(서울 10곳 기준 그대로), 공개 API 변경(없음).

| 진입점 | 한 줄 요약 | 테스트 |
|---|---|---|
| 1. 테스트 데이터 넣기 | 부팅 시드가 전국 업체 61곳 · 객실 · 업체 관리자를 더 넣는다 | 0건 |
| 2. 샘플 사진 그리기 | 업체 71곳 · 객실 그룹 사진을 다시 그린다 | 0건 |

## 1. 테스트 데이터 넣기 — `JOB user-service 부팅 시드 SAMPLE_SEED_TARGETS`

**동작 흐름**

1. **켜짐 확인** — `SEED_SAMPLE_DATA` 가 `1` 일 때만 샘플 대상을 만든다.
   - 아니면 → 아무것도 넣지 않는다(지금 그대로)
2. **업체 만들기** — 서울 10곳 뒤에 전국 61곳(번호 11 ~ 71)을 같은 모양으로 만든다 — 고정 ID · 업체코드 · 편의시설 · 소개 · 영업시간 · 판매 상품.
3. **사진 · 계정** — 업체마다 사진 2장 · 업체 총관리자 1명(`manager` / `1234`) · 회원 설정을 만든다.
4. **객실 만들기** — 업체마다 객실 그룹 2 ~ 3개 · 그룹 사진 2장 · 그룹 상품 · 호실을 만든다.
5. **없는 행만 넣기** — PK 로 이미 있는 행은 건너뛰고 나머지만 넣는다.

**입력**

| 필드 | 필수 | 설명 |
|---|---|---|
| `SEED_SAMPLE_DATA` | | `.env` — `1` 이면 테스트 데이터를 넣는다(지금 키 그대로, 새 키 없음) |

**결과**

| 상황 | 응답 | 테스트 |
|---|---|---|
| 새 개발 DB 에서 켜고 띄운다 | 업체 71곳(서울 10 + 전국 61) · 객실 · 업체 총관리자 71명 · 이용자 1명 · 문의 71건이 들어간다 | — (라이브러리 시드 — spec 을 두지 않는다, build 점검 스크립트로 확인) |
| 서울 10곳이 이미 들어간 개발 DB 에서 다시 띄운다 | 전국 61곳만 더 들어가고, 서울 10곳 · 업체 관리자가 바꾼 값은 그대로 | — (PK 로 건너뛰는 시드 틀 그대로) |
| `SEED_SAMPLE_DATA` 가 `1` 이 아니다 | 아무것도 넣지 않는다 | — (지금 분기 그대로) |
| 이용자 지도에서 "제한 없음" · 편의시설 필터로 찾는다 | 전국 업체가 가까운 순으로 나오고, 온천 · 반려동물 등으로 걸러진다 | — (API 변화 없음) |

## 2. 샘플 사진 그리기 — `CMD npm run sample:images`

**동작 흐름**

1. **폴더 비우기** — `apps/gateway/src/assets/sample/` 의 PNG 를 지운다(지금 그대로).
2. **업체 사진** — 업체 71곳마다 2장(`store-NN-1.png` · `store-NN-2.png`)을 그린다 — 그림에 업체 번호가 찍힌다.
3. **그룹 사진** — 업체별 객실 그룹마다 2장(`room-NN-G-P.png`)을 그린다.

**입력** — 없음(업체 수 · 업체별 그룹 수는 테스트 데이터와 같아야 한다)

**결과**

| 상황 | 응답 | 테스트 |
|---|---|---|
| 실행한다 | PNG 450장(업체 142 + 그룹 308)이 생기고(서울 70장은 바이트까지 그대로) 게이트웨이 `/sample/` 로 열린다 — 시드의 사진 키와 파일 이름이 하나도 어긋나지 않는다 | — (스크립트 — spec 을 두지 않는다, build 에서 파일 수 · 이름 대조) |
